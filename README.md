# حاسبة أبعاد الحاوية المثلى

حاسبة ذكية لتحديد أصغر مساحة سطحية ممكنة لحاوية تحتوي على عدد معين من العبوات ذات أبعاد محددة، مع عرض مرئي ثلاثي الأبعاد لترتيب العبوات داخل الحاوية.

## المميزات

- حساب الأبعاد المثلى للحاوية لتقليل المساحة السطحية
- عرض مرئي تفاعلي ثلاثي الأبعاد لترتيب العبوات
- دعم لجميع التوجهات الممكنة للعبوات (٦ أوضاع مختلفة لكل عبوة)
- تصميم متجاوب يعمل على جميع أحجام الشاشات

## كيفية الاستخدام

1. أدخل أبعاد العبوة (الطول، العرض، الارتفاع) بالسنتيمتر
2. أدخل عدد العبوات المطلوبة
3. انقر على زر "احسب الأبعاد"
4. استعرض الحلول المثلى مع التمثيل المرئي ثلاثي الأبعاد

## التقنيات المستخدمة

- HTML5, CSS3, JavaScript
- [Three.js](https://threejs.org/) للعرض المرئي ثلاثي الأبعاد
- تصميم RTL للغة العربية
- خط Tajawal لواجهة مستخدم متوافقة مع اللغة العربية

## المتطلبات

- متصفح ويب يدعم WebGL (Chrome, Firefox, Edge, Safari)
- اتصال بالإنترنت لتحميل مكتبة Three.js
